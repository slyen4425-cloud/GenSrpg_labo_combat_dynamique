# GenSrpG — Global Asset Library

Cette branche `global-assets` est la source stable de la bibliothèque visuelle réutilisable.

## Règle

Les branches `work/`, `preview/` et checkpoints de combat ne sont plus des sources runtime d'assets.

Les consommateurs conservent uniquement un `assetId`. Le stockage résout cet ID vers cette bibliothèque.

Racine runtime publique :

`https://raw.githubusercontent.com/slyen4425-cloud/GenSrpg_labo_combat_dynamique/global-assets/assets/library/`

Catalogue :

`data/assets/catalog/global-visual-assets.v1.json`

## Contenu consolidé

- icônes Core ;
- arène forêt ;
- créatures Capture (Maraileron, Braisombre, Loup volcanique, Golem moussu et Guêpe cybernétique : vues joueur, adversaire et icône) ;
- FX Boule de feu ;
- sprites de compétences existants ;
- casts génériques ;
- impacts génériques ;
- projectiles élémentaires.

Les fichiers sources ne portent aucune règle gameplay.
