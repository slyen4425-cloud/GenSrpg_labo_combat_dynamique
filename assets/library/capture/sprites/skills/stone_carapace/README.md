# Carapace de pierre — sprites Capture HD

Pack visuel additif pour armure / carapace de pierre. Aucun changement gameplay ou moteur.

- charge/cast : 16 PNG RGBA 512×512
- aura protectrice : 16 PNG RGBA 512×512
- 32 frames individuelles au total
- 2 atlas WebP horizontaux 8192×512
- sources de transport WebP Q95 conservées sous `assets/library/capture/sprites/source/stone_carapace_v1/`

Les atlas sont les ressources runtime du catalogue. Le pack est additif et ne remplace aucune capacité existante.
