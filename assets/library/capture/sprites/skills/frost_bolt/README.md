# Trait de givre — sprites Capture HD

Pack visuel additif de givre. Aucun changement gameplay ou moteur.

- cast/charge : 16 PNG RGBA 512×512
- projectile : 12 PNG RGBA 512×512
- impact : 12 PNG RGBA 512×512
- aura créature givrée : 16 PNG RGBA 512×512
- 56 frames individuelles au total
- 4 atlas WebP horizontaux
- l'aura utilise 250 ms/frame : les 8 dernières phases quasi fixes maintiennent visuellement l'état givré ~2 s avant la boucle
- sources de transport WebP Q90 avec alpha conservées sous assets/library/capture/sprites/source/frost_bolt_v1/

Les atlas sont les ressources runtime du catalogue. Le pack est additif et ne remplace aucun asset glace existant.
