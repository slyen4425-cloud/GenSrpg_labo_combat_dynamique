# Core Arenas

Ce dossier est la racine officielle des fonds d'arène fournis par la bibliothèque Core.

Règles :

- une famille dédiée par biome / thème ;
- noms runtime : `arena_<biome>_<variant>.webp` ;
- aucun gameplay n'est déduit de l'image ;
- les bindings d'arène utilisent des IDs d'assets stables ;
- les futurs overlays / météo / éléments de premier plan restent des assets séparés.

Biomes initiaux prévus :

- `forest/`
- `cave/`
- `snow/`
- `desert/`
- `city/`
- `sci-fi/`
- `lava/`

Assets actuellement intégrés :

- `forest/arena_forest_01.png` — forêt (format historique PNG) ;
- `lava/arena_lava_01.webp` — lave / volcan ;
- `city/arena_city_01.webp` — cité fantasy ;
- `snow/arena_snow_01.webp` — neige / glace ;
- `cave/arena_cave_01.webp` — grotte cristalline.

Les quatre nouveaux fonds fournis le 2026-09-26 sont normalisés en WebP 1536×864 (16:9) pour la bibliothèque Core.
